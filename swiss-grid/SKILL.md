# Designing with a Swiss grid

A grid gives information a clear, consistent structure. The designer's job is to make content understandable through typography, spacing, alignment and hierarchy. Readers may never see the grid, but they feel the order it creates.

For Midwestern-branded work, `midwestern-design-system` sets the actual grid numbers, type scale and colors. This skill explains the principles behind them and applies to any brand.

## Core principles

- **Clarity.** Make the main message easy to find and read. Remove elements that don't help communicate it.
- **Hierarchy.** Use differences in size, weight, position and space to show what matters first, second and third.
- **Alignment.** Give text and images shared edges. Those relationships make separate elements feel connected.
- **Consistency.** Repeat spacing, type treatments and proportions so readers can understand the layout quickly.
- **Asymmetrical balance.** A composition can feel balanced without being centered or mirrored. A large image on one side can be balanced by smaller text and open space on the other.
- **Purposeful empty space.** Blank areas separate ideas, establish emphasis and give dense information room to breathe.

## How the grid works

A grid divides the page into a set of reusable relationships.

| Part | Purpose |
|---|---|
| **Margins** | Define the space around the content |
| **Columns** | Establish widths and vertical alignment lines |
| **Gutters** | Separate columns |
| **Modules** | Divide the layout into smaller rectangular units |
| **Baseline grid** | Align the lines of text vertically across columns |

Elements can span multiple columns. On a six-column grid, a heading might span all six, an image four and a text block two. Another section can use two groups of three. The arrangement changes while the underlying proportions stay the same.

A common misunderstanding is that Swiss design means making everything equally sized and rigidly arranged. The grid keeps the proportions consistent. Emphasis comes from the composition: changes in scale, unequal column spans and generous empty space.

## Working method

1. **Write the grid down as numbers before placing anything.** Canvas, margins, column count and width, gutter, and one baseline unit. Check that the margins, columns and gutters add up exactly to the canvas width.
2. **Derive every vertical value from the baseline unit.** The unit is the body text's leading, or half of it. A smaller unit makes every number fit and stops creating rhythm. Leading for every text size is a whole multiple of the unit. Space between blocks comes from a short list of multiples (for example 1, 2, 4 and 8 units). Each new value is a new rhythm the reader has to learn. Text blocks that sit side by side share their first baseline, not just their box top.
3. **Pick one dominant element.** Make it clearly the largest or strongest thing on the page. Everything else steps down from it in two or three clear levels. If two elements are close in size, shrink one until the order is obvious.
4. **Plan the empty space as a region.** Before filling the page, choose which columns or modules stay empty and why. Empty space you planned looks intentional. Space left over after filling looks unfinished.
5. **Place every edge on a grid line.** Text, color blocks and images start and end on a column edge, a margin, or the page edge for a full bleed. Text inside a color block aligns to a column line too. Very large type may shift a few pixels so its letters look aligned to the line, since side bearings make big letters look indented.
6. **Keep a grid at every size.** Use fewer columns as the screen narrows (for example 12, then 8, then 4) and still vary the spans and indents. Stacking everything to full width removes the composition.
7. **Check it visually with the grid showing.** Render it, overlay the columns and baselines, and look for edges that miss a line, text off the baseline, competing focal points and crowded areas.

## Quick reference

| Decision | Swiss default |
|---|---|
| Text alignment | Flush left, ragged right. Avoid justified text. Center only with a reason. |
| Typefaces | One sans-serif family. Hierarchy from size and position before weight. |
| Type sizes | A short scale with clear jumps (for example 12, 16, 24, 48, 96) |
| Color | Black, white and at most one accent with one meaning |
| Dividers | Use space first. A rule only where space can't separate the content. |
| Spans | Unequal spans create tension and interest. Equal spans suit items that are equal, such as three steps. |

## Common mistakes

| Mistake | Fix |
|---|---|
| A block starts "half a gutter" off a column to look right | Move it to the column line, or bleed it to the page edge |
| One text size gets leading that breaks the baseline | Resize the text or its leading so the leading is a multiple of the unit |
| Every band of the page is full | Remove an element or merge two, then leave columns empty on purpose |
| Two big elements fight for first read | Make one clearly dominant and step the other down a level |
| Spacing values pile up (48, 64, 96, 120) | Snap each to the short list of baseline multiples |
| Everything centered and mirrored | Anchor content to the left edge and balance mass against empty space |
| Mobile turns into one full-width column | Use a 4-column grid with indents and varied spans |
| Handing off without looking | Render it and check it against the grid overlay first |
